# Workflows

Recetas por tipo de trabajo. Cada una dice **en qué orden** se usan las órdenes
del taller y qué poner en el `BRIEF.md`, para no reinventar el proceso cada vez.

| Receta | Para |
|---|---|
| [`tesis.md`](tesis.md) | tesis o trabajo de grado con revisión de literatura |
| [`monografia.md`](monografia.md) | monografía o ensayo con bibliografía |
| [`exposicion.md`](exposicion.md) | diapositivas a partir de un documento ya escrito |

Todas comparten el mismo esqueleto: **definir → investigar → verificar →
producir → entregar**, y ninguna deja producir nada que no esté respaldado.
